# PCA主成分分析算法
PCA是一种降维算法  
<img width="2448" height="1274" alt="image" src="https://github.com/user-attachments/assets/476edb3a-8cf9-44e8-95e4-f2b4a503ac97" />
只要找到一个新的坐标系，就能将一个两维成线性分布的数据转化为一个只用一维就能表示的数据。把二维信息降到一维

PCA的过程就是**找到一个坐标系**，（我们在降维的时候会把被降的那维数据投影到保留的维度上）使得数据在只保留一个维度的时候，信息损失是最小的。

怎么样最好？
找到数据分布最分散的方向（**方差最大**），作为**主成分**（坐标轴）  
<img width="1237" height="1248" alt="image" src="https://github.com/user-attachments/assets/bd886c4d-73df-4c9c-8350-39f1f9fea2b2" />
求出主成分的方法：
数据->去中心化->求协方差矩阵->分别求协方差矩阵的**特征向量**和**特征值**
->特征向量是坐标轴方向（R，旋转方向）特征值是坐标轴方向数据的方差

特征值：  
<img width="391" height="95" alt="image" src="https://github.com/user-attachments/assets/4879d201-c20c-4c5e-9271-265347259784" />
$$Y_{n_k} = X_{n_m}Q_{m*k}$$  

$Q$  

$$Y_{n_k}{Q_{m_k}}^T=X_{n_m}$$  

${Q_{m_k}}^T{Q_{m_k}}=I_{k_k}$

### 计算协方差矩阵的特征向量和特征值

由矩阵特征值特征向量的定义：

Cv=λv

其中，λ是特征向量v对应的特征值，一个矩阵的一组特征向量是一组正交向量。

特征值分解矩阵

对于矩阵C，有一组特征向量V，将这组向量进行正交化单位化，就能得到一组正交单位向量。特征值分解，就是将矩阵C分解为如下式：

C=QΣQ−1

其中，Q是矩阵C的特征向量组成的矩阵，Σ则是一个对角阵，对角线上的元素就是特征值。

```
#计算特征值和特征向量
vals, vecs = np.linalg.eig(C)
#重新排序，从大到小
vecs = vecs[:,np.argsort(-vals)]
vals = vals[np.argsort(-vals)]
```


# 相关问题解答

## 在一个二维矩阵下，为什么在去中心化的时候，只对axis=0做mean()操作？这样y（也就是axis=1）不就不是中心化的吗？那么求协方差矩阵的时候，(Y-Y.mean())就不能按照Y.mean()=0来处理了


简单直接的回答是：**当你执行 `data.mean(axis=0)` 时，你其实已经同时对 X 和 Y 进行了去中心化。**

让我们通过分解代码和数学逻辑来理清这个误区。

---

### 1. 深入理解 `axis=0` 的含义

在 NumPy 中，`axis=0` 指的是**沿着行方向**进行操作，这意味着它是对**每一列**独立求均值。

对于你的二维数组 `data`（形状为 10x2）：

- 第一列（`data[:, 0]`）是特征 **X**。
    
- 第二列（`data[:, 1]`）是特征 **Y**。
    

当你调用 `data.mean(axis=0)` 时，结果是一个包含两个值的向量：

$$\mu = [\text{mean}(X), \text{mean}(Y)]$$

### 2. 广播机制（Broadcasting）的作用

当你执行 `data_norm = data - data.mean(axis=0)` 时：

1. NumPy 用 `data` 的第一列减去 `mean(X)`。
    
2. NumPy 用 `data` 的第二列减去 `mean(Y)`。
    

因此，**`data_norm` 的每一列都已经完成了去中心化**。你可以通过以下代码验证：

Python

```
print(data_norm.mean(axis=0)) 
# 输出应该是 [0., 0.]，或者是非常接近0的浮点数
```

### 3. 为什么不使用 `axis=1`？

如果你使用 `axis=1`，计算的是**每一行的均值**。

在你的例子中，每一行代表一个“样本点”（Sample）。计算行均值意味着你在把“特征 X”和“特征 Y”相加求平均。这在物理意义上通常是没有意义的（除非 X 和 Y 的量纲完全相同且存在某种加和关系），而且这**无法**达到让每个特征的期望值变为 0 的目的。

---

### 4. 关于协方差公式的修正

由于 `data_norm` 已经去中心化了，你提取出来的 `X` 和 `Y` 其实已经满足了 $X.mean() = 0$ 和 $Y.mean() = 0$。

在你定义的函数中：

Python

```
def getcov(X,Y):
    covxy = ((X-X.mean())*(Y-Y.mean())).sum()/(len(X)-1)
    return covxy
```

虽然由于 `X.mean()` 已经趋于 0，写不写减法在数学结果上是一样的，但**保留减去均值**的操作是一个更健壮的编程习惯，因为：

1. 它能防止传入未去中心化的原始数据时出错。
    
2. 它符合协方差的标准定义：
    
    $$\text{cov}(X, Y) = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{n-1}$$
    

---

### 总结

- **`axis=0`**：计算的是每一列（特征）的均值。
    
- **去中心化效果**：减去这个均值后，X 列均值为 0，Y 列均值也为 0。
    
- **协方差计算**：既然 Y 的均值已经是 0 了，你在公式里写 `(Y - 0)` 还是 `(Y - Y.mean())` 结果是完全一致的。
    

## 为什么用numpy自带的协方差矩阵算法还要对矩阵先转置一下？
这是一个非常经典且容易让人困惑的“习惯问题”。之所以要进行转置，核心原因在于 **NumPy 对数据的默认理解（行 vs 列）与我们习惯的数据存储方式不同**。

### 1. 默认约定的冲突

在机器学习和数据分析中，我们通常习惯：

- **行（Rows）**：代表不同的**样本**（Samples/Observations）。
    
- **列（Columns）**：代表不同的**特征**（Features/Variables）。
    
    你的 `data_norm` 正是这种结构（10 行样本，2 列特征 X 和 Y）。
    

但是，`np.cov` 函数的默认设定（`rowvar=True`）是：

- **行（Rows）**：代表**变量/特征**。
    
- **列（Columns）**：代表**观测值/样本**。
    

---

### 2. 为什么要转置？

如果你直接输入 `np.cov(data_norm)`，NumPy 会认为你有 **10个特征**，每个特征只有 **2个样本**。它会尝试计算一个 $10 \times 10$ 的协方差矩阵。

为了得到我们想要的 $2 \times 2$ 矩阵（即 X 和 Y 的相关性），你有两种解决方法：

- **方法 A（转置）**：使用 `data_norm.T`。转置后，矩阵变成了 2 行 10 列，此时“行”变成了特征（X 和 Y），符合 `np.cov` 的默认胃口。
    
    Python
    
    ```
    C = np.cov(data_norm.T) 
    ```
    
- **方法 B（修改参数）**：告诉 NumPy “我的变量不在行上，而在列上”。
    
    Python
    
    ```
    C = np.cov(data_norm, rowvar=False)
    ```
    

这两个操作的结果是**完全等价**的。

---

### 3. 数学本质的验证

协方差矩阵的数学定义通常表示为：

$$C = \frac{1}{n-1} \mathbf{X}^T \mathbf{X}$$

_(注：这里的 $\mathbf{X}$ 是去中心化后的矩阵，且约定样本为行，特征为列)_

- 如果你的 `data_norm` 是 $10 \times 2$，那么 $10 \times 2$ 的矩阵是不能直接和自己做点积的。
    
- 你需要用 $(2 \times 10)$ 的矩阵乘以 $(10 \times 2)$ 的矩阵，才能得到一个 $(2 \times 2)$ 的结果。
    

这就是为什么在代码层面，我们需要通过转置或者设置 `rowvar=False` 来调整维度对齐。

---

### 总结

`np.cov` 默认每一行是一个变量。因为你的每一列才是变量，所以要么**转置**它，要么**显式告诉它 `rowvar=False`**。

既然协方差矩阵已经算出来了，**你想接下来看看如何计算特征值（Eigenvalues）和特征向量（Eigenvectors）来完成 PCA 的最后一步吗？**


## 第一： $\Sigma$  在新轴上进行缩放（拉伸程度就是特征值）这个缩放是原椭圆形数据不动，坐标进行缩放吗，可这有什么意义呢，还是说原椭圆形数据先被压缩了，再被放开？第二：为什么 $Q$  是正交矩阵，意味着 $Q^{-1} = Q^T$，我知道转置，那么 $Q^{-1} = Q^T$ 是什么意思

这两个问题直戳 PCA 的数学心脏！我们不需要死记硬背公式，通过**几何变换**的视角来看，一切都会变得非常直观。

---

### 1. 关于 $\Sigma$ 的缩放：是“数据”的缩放，还是“空间”的缩放？

你问“缩放有什么意义”，这是一个深刻的洞察。

在 $C = Q\Sigma Q^T$ 这个分解公式中，我们其实是在做**逆向工程**：

- **原始数据 $data$**：是一团倾斜的、扁平的椭圆。
    
- **协方差矩阵 $C$**：描述了这团椭圆的形状。
    

**$\Sigma$ 的意义在于“归一化”或“去相关”:**

想象你把这个倾斜的椭圆先**旋转**（通过 $Q^T$ ）使其长轴和短轴与坐标轴平行，此时数据依然是椭圆。

接着，$\Sigma$（对角阵，元素是特征值的平方根）的作用是把这个椭圆**拉伸或压缩**成一个标准的**正圆**。

**为什么要这么做？**

在机器学习中，如果我们能把复杂的相关数据（椭圆）变成独立无关的数据（正圆），处理起来就简单多了。在 PCA 中，特征值 $\lambda$ 告诉我们：**在这个方向上，数据的“信息量”（方差）有多大**。

- 如果某个特征值 $\lambda$ 接近 0，说明这个方向上的圆变成了“一条线”，几乎没有信息，我们可以直接丢弃它（实现降维）。
    

---

### 2. 为什么 $Q$ 是正交矩阵，以及 $Q^{-1} = Q^T$ 是什么意思？

这是一个非常神奇的线性代数特性。

#### 什么是正交矩阵？

如果一个矩阵 $Q$ 的每一列都是**单位向量**（长度为 1），且两两之间**互相垂直**（内积为 0），那么它就是正交矩阵。

在 PCA 中，特征向量 $v_1$ 和 $v_2$ 刚好满足这两个条件。

#### $Q^{-1} = Q^T$ 是什么意思？

- **$Q^{-1}$（逆矩阵）**：代表“撤销”或“还原”某种变换的操作。如果 $Q$ 把空间旋转了 30°，那么 $Q^{-1}$ 就把它转回 -30°。
    
- **$Q^T$（转置矩阵）**：仅仅是把行和列交换。
    

**物理意义：**

对于正交矩阵（旋转矩阵）来说，**“反向旋转”的操作在数学上正好等于它的“转置”**。

$$Q^T Q = I \quad (\text{单位矩阵})$$

这在计算上极其方便！在普通的矩阵运算中，求逆矩阵（$Q^{-1}$）计算量巨大且容易出错；但在 PCA 中，我们只需要把矩阵躺下来（转置），就直接得到了它的逆。

---

### 3. 实战：将 10 个点投影到 PC1

现在，让我们把这 10 个原始点投影到你算出的第一个特征向量 $v_1 = [0.9426, 0.3340]$ 上。

**逻辑是：** 原始数据点 $P$ 与单位方向向量 $v_1$ 做**点积（Dot Product）**。

Python

```
# 1. 提取第一个特征向量 (PC1)
pc1 = vecs[:, 0]  # array([0.9426, 0.334 ])

# 2. 将去中心化的数据投影到 PC1 上
# 点积公式：projection = data_norm · pc1
data_1d = data_norm @ pc1

print(data_1d)
# 输出是一个 (10,) 的一维阵，这 10 个数字就是数据在主轴上的“新坐标”
```

**你会发现：**

原本需要两个数 $(x, y)$ 才能表示的一个点，现在只需要**一个数**就能表示它在最主要方向上的位置。虽然丢失了一点点信息（PC2 方向上的分量），但保留了最核心的特征。
